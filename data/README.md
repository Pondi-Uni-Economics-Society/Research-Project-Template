# Data notes

Keep data documentation here, not confidential source records. Record file names, unit of observation, variable meanings, units, missing-value codes, transformations, source URLs, access dates, and terms of use.

Prefer linking to the Society’s shared [Database- repository](https://github.com/Pondi-Uni-Economics-Society/Database-) rather than copying its files. Only place data in this project repository when the team has authority to share it with every repository collaborator. Never commit personal, confidential, restricted, or consent-limited data, even if this repository is private.
