# Reproducibility guide

## Software and versions

Record operating system, software, package versions, and any external tools needed.

## Data sources

Document where each input came from, its access date, license or terms, and how a researcher can obtain it. Do not commit restricted data or personal identifiers.

## Run the analysis

Write the commands in order, starting from a fresh copy of the repository. Explain any manual steps and expected output files.

## Checks

Describe tests, data checks, and expected results. Explain known limitations and any results that may vary across software versions.
